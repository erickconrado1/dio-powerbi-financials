# Sales & Financials — Power BI

Projeto desenvolvido como desafio prático do curso de Análise de Dados da DIO.

## Sobre o projeto

Desenvolvimento de um relatório gerencial de vendas utilizando a base Financial Sample e o Power BI.

O projeto contempla:

- Indicadores de vendas, lucro, margem e unidades vendidas;
- Análise temporal das vendas;
- Análise por segmento;
- Análise por produto;
- Análise por país;
- Segmentadores de dados;
- Navegação entre páginas;
- Indicadores (bookmarks);
- Botões para alternância de visuais;
- Publicação no Power BI Service.

## Páginas

### Visão Geral

Dashboard executivo com os principais indicadores e análises de vendas.

### Análise Detalhada

Análise complementar com indicadores e alternância entre diferentes visuais utilizando indicadores e botões.

## Ferramentas

- Power BI Desktop
- Power BI Service
- GitHub

## Base de dados

Financial Sample — Microsoft Power BI.
